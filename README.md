# Easy Translate (ET) · VS Code 使用说明

在 VS Code 编辑器中选中文本，译文直接以悬浮窗显示在选区附近。支持 OpenAI 兼容接口、有道、百度、DeepL 和 Google 翻译服务。

---

## 1. 快速开始

### 1.1 配置翻译引擎（首次必做）

1. 打开命令面板：`Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）。
2. 运行 **ET: 管理翻译引擎**。
3. 点击 **添加引擎**。
4. 选择 **引擎类型**，填写对应配置（见 3.4 节速查表）。
5. 点击 **测试连接**，确认返回测试译文。
6. 点击 **保存引擎**。
7. 在引擎列表中点击 **设为默认**。

> API Key、appSecret 等凭证保存在 VS Code SecretStorage 中，不会写入 `settings.json`。

### 1.2 翻译第一段文本

1. 在编辑器中用鼠标或键盘选中文本。
2. 停止选择约 250 毫秒后，选区附近会自动出现浮窗，并显示“正在翻译，请稍候…”。
3. 翻译完成后，浮窗直接显示译文。

### 1.3 开关划词自动翻译

状态栏右侧有 **ET** 按钮：

| 显示 | 含义 |
| --- | --- |
| 图标高亮 + `ET` | 已开启：选中文本自动翻译 |
| 图标带斜线 + `ET` | 已关闭：不自动翻译，仍可右键手动翻译 |

点击按钮即可切换，状态自动保存；关闭时会同时收起当前浮窗。

## 2. 核心功能使用步骤

### 2.1 悬浮翻译

1. 选中要翻译的文本。
2. 等待约 250 毫秒，浮窗出现。
3. 浮窗显示引擎名称、目标语言和译文。

浮窗内提供四个操作：**复制**、**译为 English / 译为简体中文**、**固定浮窗**、**替换原文**。

### 2.2 复制译文

1. 完成一次翻译。
2. 点击浮窗中的 **复制**。
3. 状态栏提示“ET：译文已复制”，译文已写入剪贴板。

### 2.3 切换译文语言

1. 完成一次翻译。
2. 点击浮窗中的 **译为 English**（当前为中文时）或 **译为简体中文**（当前为英文时）。
3. 浮窗会重新翻译，并把该语言保存为新的目标语言。

### 2.4 固定浮窗

1. 完成一次翻译。
2. 点击 **固定浮窗**。
3. 之后取消选区，浮窗也不会自动关闭；再次点击 **取消固定** 恢复自动关闭。

### 2.5 替换原文

1. 完成一次翻译。
2. 点击 **替换原文**。
3. 译文会直接写入选区所在位置，可按 `Ctrl+Z` 撤销。

> 若原文在翻译期间被修改，会提示“原文已发生变化，请重新选择并翻译”。

### 2.6 手动翻译

自动翻译关闭时，仍可手动触发：

- **右键菜单**：在编辑器中选中文本 → 右键 → **翻译选中内容**。
- **命令面板**：`Ctrl+Shift+P` → **ET: 翻译选中内容**。

### 2.7 取消当前翻译

- 浮窗打开时按 `Esc`：立即终止请求并关闭浮窗。
- 或打开命令面板运行 **ET: 取消当前翻译**。

### 2.8 切换默认引擎

1. 打开命令面板。
2. 运行 **ET: 选择默认翻译引擎**。
3. 在列表中选择目标引擎。

未配置任何引擎时，会提示先添加引擎。

### 2.9 修改目标语言

任选一种方式：

- 打开 **ET: 管理翻译引擎**，在顶部“目标语言”下拉框中选择并保存。
- 命令面板运行 **ET: 设置目标语言**，输入语言名称或代码。
- 点击浮窗中的 **译为 English / 译为简体中文** 快速切换。

下拉框提供 **简体中文** 和 **English** 两个选项，与浮窗的中英互译保持一致；若当前值来自命令输入的其他语言或代码，会临时出现在列表首项。

### 2.10 处理翻译失败

浮窗会直接显示失败原因，并提供 **管理引擎** 链接。常见提示：

- `尚未设置默认翻译引擎，请先点击“管理引擎”完成配置`
- `翻译处理超时，请检查网络和引擎配置后重试`
- HTTP 错误及服务返回的错误信息

## 3. 常用操作示例

### 3.1 阅读英文代码注释

1. 选中英文注释。
2. 浮窗自动显示中文译文。
3. 阅读完毕后移动光标或按 `Esc` 关闭。

### 3.2 把中文注释改写为英文

1. 选中中文注释。
2. 点击浮窗中的 **译为 English**。
3. 确认译文后点击 **替换原文**。

### 3.3 对照长文本翻译

1. 选中长段落。
2. 翻译完成后点击 **固定浮窗**。
3. 继续滚动或编辑文件，浮窗保持显示。

### 3.4 引擎配置速查表

| 引擎类型 | 必填凭证 | 默认 Base URL |
| --- | --- | --- |
| OpenAI 兼容接口 | 模型；API Key 视服务而定 | `https://api.openai.com/v1` |
| 有道官方 API | appKey、appSecret | `https://openapi.youdao.com` |
| 百度翻译 API | appid、secretKey | `https://fanyi-api.baidu.com` |
| DeepL API | Auth Key | `https://api.deepl.com/v2`（免费版改为 `https://api-free.deepl.com/v2`） |
| Google 官方 API | API Key | `https://translation.googleapis.com` |
| Google 免费端点（非官方） | 无需密钥 | `https://translate.googleapis.com` |

Base URL 只填写 API 根路径，不要包含 `/chat/completions` 等具体接口路径。

### 3.5 常用设置项

在 VS Code 设置中搜索 **Easy Translate** 即可修改：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| `selectionTranslator.autoTranslate` | `true` | 划词后自动翻译；与状态栏 ET 按钮联动 |
| `selectionTranslator.hoverAutoHideDelay` | `800` | 取消选区后浮窗延迟关闭的毫秒数，`0` 为立即关闭 |
| `selectionTranslator.targetLanguage` | `简体中文` | 默认目标语言，支持名称或代码 |

## 4. 常见问题

- **选中文本后没有浮窗**：确认状态栏 ET 按钮为高亮开启状态，且已设置默认引擎。
- **提示尚未设置默认引擎**：运行 **ET: 管理翻译引擎**，添加引擎并点击 **设为默认**。
- **测试连接失败**：检查 Base URL 是否为 API 根路径、密钥是否正确、模型名是否存在。
- **请求返回 404**：Base URL 不要填写 `/chat/completions`，只填到 API 根路径。
- **`Esc` 无法关闭浮窗**：先点击编辑区让键盘焦点回到编辑器，再按 `Esc`。
- **替换原文后想恢复**：按 `Ctrl+Z` 撤销。
